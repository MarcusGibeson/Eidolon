# Eidolon product definition

Eidolon is a local, persistent artificial-mind research system and supervised software-development assistant: it should converse naturally, preserve user-attributable memory with provenance, reason and plan under uncertainty, use bounded tools, and prepare or execute software work only inside explicit operator-governed authority boundaries. Conversation and supervised development are two surfaces of the same product, not separate products. A capability is considered part of the active product only when it is reachable from a supported runtime surface and has behavioral or integration evidence; historical checkpoint/report modules are retained compatibility material until consolidated and are not, by themselves, evidence that a capability works.
