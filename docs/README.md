# Eidolon Active Documentation

This directory contains only documentation and metadata still required by current source, verification, compatibility, or operator procedures. Historical evidence is retained under `archive/docs/` and is indexed by SHA-256 in `archive/docs/DOCUMENT_ARCHIVE_MANIFEST.json`.

## Active policy

- Keep current operational/reference material active.
- Move completed roadmaps, milestone ledgers, bundle reviews, handoffs, and validations to the archive.
- Redirect executable path dependencies before retiring a document.
- Never discard historical evidence merely to reduce file count.
