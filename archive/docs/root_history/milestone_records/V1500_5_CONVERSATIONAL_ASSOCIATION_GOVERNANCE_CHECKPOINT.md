# v1500.5 Conversational Association Governance and Feedback Checkpoint

This checkpoint connects explicit conversational corrections and reversible forget requests to the same revision-bound durable association service used by the operator inspector.

- One explicit correction updates one exact active association and preserves lineage.
- One explicit forget request retracts one exact active association reversibly.
- Unknown and ambiguous targets fail truthfully without mutation.
- Permanent deletion remains a separate operator-confirmed inspector action.
- Mutation responses come from actual local results; no provider is contacted.
- Dashboard actions preserve conversation identity, open-state, and association return location.
- Immediate working feedback remains visible while the large chat console refreshes.
