# v1258.0-v1258.9 Complete Application Construction Review

v1258 extends the existing v1254-v1257 supervised development pipeline so Eidolon can treat a multi-file application as one coherent product rather than a pile of individually plausible files.

## Delivered

- A sealed complete-application construction contract tied to the existing coding request and source/workspace lineage.
- Cooperating artifact roles, explicit cross-file relationships, assumptions, uncertainty, completion conditions, and blocker conditions.
- Seven deterministic quality dimensions covering interface coherence, dependencies, configuration, tests, documentation, accessibility, and responsive behavior.
- Provider integration through the existing v1254 isolated execution path, with no parallel execution engine.
- Cross-file quality verification integrated into the existing verification result and v1257 diagnostic-repair loop.
- Ordinary-chat activation only for explicit broad application requests; narrow edits remain narrow.
- Reliability hardening for broken local references, missing artifacts, undeclared dependencies, accessibility/responsive omissions, casefold collisions, link contamination, long paths, stale source, cancellation, and quality-record tampering.
- Read-only health inspection, operator handoff, and a read-only v1258.9 checkpoint.

## Authority boundary

Passing v1258 quality checks does not grant selected-project application, dependency installation, unrestricted shell execution, promotion, certification, release, permanent approval, or independent self-update. Application remains separately governed by v1255. v1258 does not contact providers or execute tests during its read-only .9 checkpoint.
