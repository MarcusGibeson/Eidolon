# Eidolon v1348.9 Dependency Selection Final Validation

- Evaluates supplied/local dependency evidence without network or registry contact.
- Prefers an adequate existing dependency over adding a new one when both are viable.
- License, security, provenance, freshness, footprint, platform support, offline suitability, and capability fit are explicit gates.
- Public receipts retain digests and reason counts rather than candidate names.
- Selection grants no package installation, lockfile mutation, publication, source application, or release authority.
