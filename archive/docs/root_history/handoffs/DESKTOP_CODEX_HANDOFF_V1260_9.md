# Desktop Codex Handoff: Eidolon v1260.9 Coding Alpha Checkpoint

## Candidate intent

Validate the Coding Alpha integration milestone on native Windows. The checkpoint should be treated as a supervised development candidate only. Do not install, promote, certify, release, or broaden authority during review.

## Canonical campaign

Use an ordinary selected-project request equivalent to “Build me a complete responsive accessible calculator webpage.” Verify the full path:

1. Conversational action classification creates one supervised development proposal.
2. Generic “go ahead” remains blocked.
3. Exact proposal approval prepares the v1254 isolated request, inspection, plan, workspace, and execution packet.
4. Exact isolated execution performs implementation and bounded verification only in the disposable workspace.
5. Force or observe one deterministic failure, verify v1257 diagnostic evidence, and confirm the repair does not repeat an unchanged failed strategy.
6. Restart Eidolon and resume the v1256 session; confirm no duplicate provider call or duplicate execution.
7. Review the exact diff/evidence.
8. Prepare v1255 controlled application and confirm the selected project is still unchanged.
9. Use the exact application authorization; confirm post-apply verification passes.
10. Replay the exact application authorization and confirm it is idempotent.
11. Prepare and separately authorize rollback.
12. Confirm byte-for-byte restoration of the pre-apply project tree.

## Native Windows focus

- Real NTFS junction and reparse-point containment.
- Case-insensitive aliases and casefold collisions.
- Long paths under the actual operator environment.
- Cross-process duplicate proposal/execution/application/rollback controls.
- Restart during isolated execution, diagnostics, immediately before application, during application recovery, and during rollback recovery.
- Operator edits to unrelated files versus conflicting edits to candidate paths.
- Provider outage and verifier/tooling outage classification.
- Dashboard presentation of plan, progress, diff, tests, exact approvals, cancellation, recovery, and rollback.

## Required boundary

No successful checkpoint result authorizes installation, promotion, certification, release, permanent approval, autonomous self-update, or independent development authority. v1261 remains a separate next arc.
