# v1289.0-v1289.2 Product Quality Judgment Foundations

Introduces read-only evidence normalization and six independent quality dimensions: coherence, usability, accessibility, maintainability, completeness, and operator readiness. Each dimension requires a relevant specialized evidence type. Deterministic tests alone are explicitly insufficient; stale evidence is ignored and exact duplicate evidence is suppressed.

No quality evidence grants provider, execution, test, repair, mutation, application, update, rollback, release, or standing authority.
